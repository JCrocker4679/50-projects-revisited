# 50 Projects Revisited

Revisiting tutorial projects (Traversy Media's 50 Projects in 50 Days, Frontend Mentor, etc.) with a product manager's eye and AI-assisted development — refactoring them from tutorial code into production-viable applications.

## What this is

Each project gets a PM-style review, a full team of AI expert agents weighing in, and an iterative refactor managed through GitHub Issues and PRs — just like a real development team. The work then gets turned into YouTube/blog content documenting the journey.

This is NOT a coding tutorial. It's a product-thinking series about the gap between "I followed a tutorial" and "this is a real product."

## Structure

```
projects/
  {project-name}/
    original/         # Original tutorial code, preserved as-is
    refactored/       # The improved version
    reviews/          # Expert agent assessments
    sprints/          # Sprint plans and reviews
    assets/           # Screenshots, recordings, design files
    REVIEW.md         # PM audit & refactor plan
    DECISIONS.md      # Product decisions that drive sprint planning
    CHANGELOG.md      # What changed and why

blog/                 # Blog posts / video scripts / content plans
notes/                # Working notes, vision docs, model comparisons
.claude/commands/     # Slash commands for the AI workflow
```
